## In one sentence
The interface I_U[x | y] is what an agent can observe of its environment: the probabilities of observations x given actions y. The mechanism is the hidden-state machine that produces them. Every mechanism gives one interface, many mechanisms give the same interface, and from inside the loop the agent only ever has the interface.

## Twist
A world model can be right about everything an agent can see and still be wrong about how the world works inside.
